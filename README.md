# CryptoAlert

CryptoAlert is a web application that helps users track cryptocurrency portfolios and receive price-threshold alerts.

## Features
- Portfolio tracking
- Profit/Loss calculation
- Price alerts
- Alert history
- Investor and Analyst roles
- Responsive design

## Tech Stack
- HTML
- CSS
- Bootstrap 5
- JavaScript
- LocalStorage
